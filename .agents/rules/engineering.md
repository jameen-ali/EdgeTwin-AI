# EdgeTwin Engineering Rules

These rules apply to all engineering work:
- one task at a time
- read rules/tasks/memory before work
- do not invent requirements
- preserve existing work
- no secrets
- reproducibility
- tests required
- validate before claiming completion
- update tasks.md
- update memory.md
- do not modify unrelated scope
- no uncontrolled refactoring
- no fabricated research/data/results
- use [FACT], [DECISION], [PROPOSED], [ASSUMPTION]
